# Как обновлять страницу «Команда сейчас»

## Вручную (всегда работает)
1. На сайте РФБ откройте три страницы и сохраните каждую (Ctrl+S, «Веб-страница, только HTML»):
   - Суперлига → Положение
   - Суперлига → Матчи
   - Кубок России → Матчи
2. Запустите: python3 tools/update_data.py --files положение.html суперлига.html кубок.html
3. Загрузите папку сайта в Netlify Drop заново.

## Автоматически (GitHub)
1. Создайте аккаунт и пустой репозиторий на github.com, загрузите туда все файлы сайта (включая папку .github).
2. Подключите репозиторий к Netlify (Add new site → Import from Git) или включите GitHub Pages.
3. Вкладка Actions → «Обновление данных РФБ» → Run workflow для проверки. Дальше запуск каждые 30 минут.
Если GitHub не сможет открыть сайт РФБ, в Actions будет ошибка, а старые данные останутся на сайте. Тогда используйте ручной способ.
